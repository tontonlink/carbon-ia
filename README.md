# carbon-ia
Carbon-ia est un outil open-source permettant de mesurer l’impact carbone des usages d’intelligence artificielle. Le projet vise à fournir un calcul transparent, reproductible et extensible du CO₂ émis par les requêtes IA, en cloud ou en local, afin de sensibiliser et d’encourager la sobriété numérique.

## Objectifs
- Mesurer l’empreinte carbone des requêtes IA (CO₂/token, énergie, eau).
- Comparer les usages cloud vs local.
- Fournir des graphiques temporels (jour, semaine, mois).
- Proposer des recommandations de sobriété IA.
- Offrir une architecture modulaire pour accueillir des modèles IA variés.

## Fonctionnalités prévues
- Extension navigateur pour analyser les requêtes IA.
- Calculateur CO₂ basé sur des facteurs scientifiques.
- API locale pour le calcul et le stockage.
- Interface web légère (HTML/CSS/JS).
- Mode offline pour consultation locale.
- Modules additionnels pour nouveaux modèles IA.
